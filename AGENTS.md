# Project continuity

Before continuing work in this repository, read [the session handoff](docs/SESSION_HANDOFF.md). It records the implemented architecture, user preferences, private-configuration locations, verified integrations, outstanding work, and uncommitted changes.

Preserve existing work. Never print or commit credentials from `.env` or ignored `data/`. Keep real public observations, hypothetical scenario assumptions, and synthetic simulation state clearly distinguished. The user wants public inputs loaded automatically when opening the app.

Update the handoff when significant implementation or verification status changes. Runtime process IDs and source observations in it are historical; check current state before acting.
